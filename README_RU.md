# RGB Lighting — проект-заготовка для Minecraft 26.2 Fabric

Это **исходный проект**, а не готовый `.jar`. Он задаёт структуру мода, метаданные Fabric и базовые модели RGB-цвета/источника света. Реальное изменение освещения, команды, сетевые пакеты и тени пока не реализованы.

## Цель проекта

- Minecraft Java 26.2 / Fabric
- Сервер хранит настройки; клиенты получают одинаковый список источников света
- Все игроки с установленным клиентским модом видят одинаковый эффект
- Оператор управляет настройками
- Приоритет: Android + MojoLauncher + GL4ES
- Без обязательных шейдеров и без прямых вызовов OpenGL

## Текущий этап 0.1.0

Уже есть:
- каркас Fabric-мода с common/client entrypoints;
- базовая модель RGB (0–255) и hex-представление;
- модель определения источника света;
- зависимости и параметры сборки для ветки 26.2.

Пока отсутствует:
- настоящая цветная подсветка блоков/мобов;
- команды `/rgb`;
- серверное сохранение и синхронизация;
- прожектор;
- цветные тени;
- проверка запуска на GL4ES.

## План разработки

1. **Серверная основа:** команды оператора, сохранение данных мира, проверка прав и синхронизация всем клиентам.
2. **Первая клиентская подсветка:** цветное освещение от заданных координат с ограничением радиуса и количества активных источников.
3. **Настройка блоков и мобов:** отдельная запись для блока, типа блока или конкретной сущности.
4. **Прожектор:** направление, дальность, ширина луча, RGB, включение/выключение; управление оператором.
5. **Тени:** отдельный экспериментальный этап. Цветные тени существенно сложнее обычной цветной подсветки.
6. **Профиль Android:** низкий лимит источников, обновление не каждый кадр, дальность и эффекты отключаются в настройках.

## Сборка

Требуется JDK 25 и Gradle 9.5.1. В `gradle.properties` заданы версии для Fabric 26.2; при изменении официальных версий их нужно согласованно обновить.

В папке проекта выполнить:

```bash
gradle build
```

Готовый мод (если сборка прошла успешно) будет в `build/libs/`.

## Установка для теста

1. Сначала собрать проект на компьютере или в совместимой среде разработки.
2. Скопировать итоговый `rgb-lighting-0.1.0.jar` в `mods` на сервере и в `mods` каждого клиента.
3. Установить совместимые Fabric Loader и Fabric API для Minecraft 26.2.
4. Сделать резервную копию мира перед тестированием.

На текущем этапе этот каркас **не добавляет игровую функцию освещения**. Не устанавливай его как готовый функциональный мод.

## Важные ограничения GL4ES

Minecraft 26.2 требует использовать слой Blaze3D вместо прямых вызовов OpenGL для совместимости с графическими backend'ами. Поэтому рендеринг надо писать через поддерживаемые игровые абстракции. Совместимость конкретно с MojoLauncher + GL4ES нельзя честно гарантировать без запуска на самом устройстве.

Также сервер не может заставить немодифицированный клиент отрисовать новые цветные источники света: для одинакового результата клиентский мод должен стоять у каждого игрока.


## Автоматическая сборка через GitHub Actions

В проект добавлен workflow `.github/workflows/build.yml`.

1. Создай новый репозиторий на GitHub.
2. Загрузи **всё содержимое** этой папки в корень репозитория (включая скрытую папку `.github`).
3. Открой вкладку **Actions** и выбери workflow `Build RGB Lighting`.
4. После успешного запуска открой завершённый запуск и скачай артефакт `rgb-lighting-build` в разделе Artifacts.

Workflow запускается при push, pull request и вручную через **Run workflow**. Для сборки используется Temurin JDK 25 и Gradle 9.5.1.

Примечание: GitHub Actions автоматизирует только компиляцию. Успешная сборка не означает, что игровые функции RGB уже реализованы или что мод проверен на MojoLauncher/GL4ES.
